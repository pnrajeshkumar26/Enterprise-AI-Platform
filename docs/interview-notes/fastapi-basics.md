# FastAPI Basics

## What is FastAPI?

FastAPI is a modern ASGI web framework for building high-performance REST APIs using Python.

---

## Why FastAPI?

- High performance
- Async support
- Automatic OpenAPI documentation
- Pydantic validation
- Type hints
- Excellent for AI APIs

---

## What is Uvicorn?

Uvicorn is an ASGI server that runs FastAPI applications.

---

## What does this command mean?

uvicorn app.main:app --reload

app -> Python package

main -> main.py

app -> FastAPI object

--reload -> Automatically reload after code changes

---

## Why is FastAPI popular for LLM APIs?

- High concurrency
- Easy REST API development
- Swagger documentation
- Excellent async performance
